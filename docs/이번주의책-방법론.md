# '이번 주의 책' 만드는 법 — 방법론

신문 책 코너 기사를 모아 **이번 주 신문들이 소개한 책**을 뽑고, 표지·저자·출판사·ISBN을 붙여 보여 주는 방법을 정리한 문서입니다.
지금 사이트(지금 뜨는 뉴스 › 책책책 탭)에서 실제로 쓰는 규칙과 수치를 그대로 옮겼습니다. 다른 프로젝트에서 이 문서만 보고 다시 만들 수 있게 썼습니다.

- 작성: 2026-10-24
- 코드: `trend_site.py`(k7book/news 저장소, PC 폴더 `E:\AI 프로젝트\31_뉴스`). 함수 이름은 각 단계 끝에 적었습니다.
- 사용 언어: 파이썬 3 표준 라이브러리만(외부 패키지 없음)

---

## 1. 한눈에 보는 흐름

```
① 기사 모으기        신문 책 코너 RSS 6곳 + 구글뉴스 '신간·새책' 검색 3개
        │            (최근 7일, 책 기사만 거르기, 중복 제거)
② 요약 채우기        RSS 요약 → 없으면 원문 페이지의 소개글(og:description)
        │
③ 책 이름 뽑기       기사 제목·요약에서 『』, ‘제목’(출판사), [신간] 뒤 제목 등 7가지 규칙
        │
④ 책 단위로 모으기   같은 책 = 낱말만 남긴 제목이 같은 것. 소개한 신문사·기사 목록을 묶음
        │            순서: 소개한 신문사 수 ↓ → 최근 소개일 ↓
⑤ 서지 정보 붙이기   예스24 검색: 정확한 책 이름·저자·출판사·출간 연월·표지
        │            교보문고 검색: ISBN-13
        │            (한 번 찾은 책은 저장, 못 찾은 책은 하루 한 번 다시)
⑥ 보여 주기          표지 진열대 + 책 정보 창 + 분류된 책 기사 목록
```

현재 성적(2026-10-24 04:59 기준, 최근 7일):

| 항목 | 값 |
|---|---|
| 모은 책 기사 | 122건 (독서신문 25, 조선 21, 한겨레 19, 동아 18, 경향 11, 파이낸셜뉴스 11, 연합 5, 뉴시스 4, 매경 3, 한경 3, 뉴스1 1, 이데일리 1) |
| 책 이름이 뽑힌 기사 | 50건 (41%) |
| 뽑힌 책 | 49권 (두 곳 이상이 소개한 책 3권) |
| 서점 정보가 붙은 책 | 43권 (88%) · ISBN 43권 |

## 2. 기사 모으기 (`fetch_books`)

### 2-1. 출처

**RSS로 받는 곳 (6곳)**

| 신문 | 코너 | RSS | 책 기사만 거르는 방법 |
|---|---|---|---|
| 동아일보 | 책의 향기 | `https://rss.donga.com/book.xml` | 전부(책 전용 RSS) |
| 조선일보 | 책(토요일 Books) | `https://www.chosun.com/arc/outboundfeeds/rss/category/culture-life/?outputType=xml` | 주소에 `/culture-life/book/`가 든 기사 |
| 한겨레 | 책과 생각 | `https://www.hani.co.kr/rss/culture/` | 주소에 `/arti/culture/book/`가 든 기사 |
| 경향신문 | 책 · 책과 삶 | `https://www.khan.co.kr/rss/rssdata/culture_news.xml` | 제목 규칙(아래 `BOOK_TITLE_RX`) |
| 연합뉴스 | 책/문학 | `https://www.yna.co.kr/rss/culture.xml` | 제목 규칙 |
| 독서신문 | (책 전문지) | `https://www.readersnews.com/rss/allArticle.xml` | 제목·요약에 책 관련 낱말(책·도서·출판·작가·지음·『 등)이 있는 기사만 — 전체 기사 RSS라 피자·카톡 같은 일반 기사가 섞임 |

제목 규칙(경향·연합처럼 문화 RSS에 책 기사가 섞인 곳):

```python
BOOK_TITLE_RX = r"\[(?:책과 ?삶|신간|새책|책|책꽂이|책의 향기|북리뷰|이 책|서평|금주의 신간|북스|책마을|.txt)[^\]]*\]|신간|새책|출간|펴냄|북토크|그림책|시집|소설집|에세이|문학상|부커상|노벨문학상"
```

**RSS가 없는 곳 → 구글뉴스 검색 RSS**

중앙·한국·문화·서울·국민일보, 뉴시스, 뉴스1, 파이낸셜뉴스 등은 책 코너 RSS가 없습니다. 이 신문들이 제목에 '신간·새책'을 붙인 기사만 구글뉴스 검색으로 받습니다.

```
https://news.google.com/rss/search?q=<검색어>&hl=ko&gl=KR&ceid=KR:ko
검색어: "intitle:신간 when:3d", "intitle:새책 when:7d", "intitle:책꽂이 when:7d"
```

- 구글뉴스 검색은 온갖 전문지(복지·의학·농업지 등)가 섞이므로 **주요 언론사 목록**(`BOOK_SEARCH_OUTLETS`, 29곳)에 든 것만 남깁니다.
- 언론사 이름은 항목의 `<source>` 글자를 씁니다. 제목 끝의 ` - 언론사`는 지웁니다.

### 2-2. 정제 규칙

| 규칙 | 내용 |
|---|---|
| 기간 | 최근 **7일**(책 코너는 주 1회 지면이 많아 하루치로는 부족) |
| 날짜 없는 피드 | 한겨레 문화 RSS는 기사마다 발행 시각이 없음 → 사진 주소의 날짜(`/2026/1023/`)를 그날 09시로 사용 |
| 깨진 XML | 제어 문자 지우고, 엔티티가 아닌 맨 `&`를 `&amp;`로 바꿔 다시 읽기(연합뉴스 사회 RSS에서 실제로 발생) |
| 사진 | `media:content`·`enclosure`·본문 첫 `<img>`. 따옴표 없는 `src=...`도 읽기(한겨레) |
| 중복 | (신문사, 낱말만 남긴 제목 앞 40자)가 같으면 하나만 |
| 요약 | RSS `description`의 글자만(태그 제거), 220자에서 자름. 요약이 제목을 되풀이만 하면 버림 |
| 빼는 기사 | 연재소설(`[12화]`), 제목이 태그뿐인 기사(`[책꽂이]`) |
| 개수 | 최신순 150건까지 |

### 2-3. 요약·사진 채우기 (`enrich_books`)

RSS에 요약이 없는 기사(한겨레, 구글뉴스로 온 기사)는 원문 페이지를 한 번 읽어 채웁니다.

1. 구글뉴스 링크면 원문 주소로 풉니다(`gn_decode`).
2. 원문 페이지에서 `og:description`(없으면 `description`)과 `og:image`를 읽습니다. 원문 사이트의 robots.txt가 막으면 읽지 않습니다.
3. 한겨레는 RSS 사진이 **300×180으로 잘린 사진**이므로, 원문의 `og:image`(원본 크기, 대개 책 표지)로 바꿉니다.
4. 결과는 `history/book_meta.json`에 저장해서 다음부터는 새 기사만 읽습니다(한 번에 최대 60건).

## 3. 책 이름 뽑기 (`book_titles_of`)

기사 하나의 **제목 + " ‖ " + 요약**을 이어 붙인 글에서 아래 규칙으로 책 이름을 찾습니다. 한 기사에서 여러 권이 나올 수 있습니다.

| # | 규칙 | 정규식(요지) | 예 |
|---|---|---|---|
| 1 | 겹낫표 | `『([^』]{2,40})』` | [신간] 『한 줄 메모의 힘』 |
| 2 | 겹화살괄호 | `《([^》]{2,40})》` | 《…》 |
| 3 | 따옴표 + (출판사) | `[‘'“"](…{2,40})[’'”"]\s*\((…{1,25})\)` — 괄호 안에 글자 2자 이상일 때만(나이 `(64)` 제외) | 1144쪽짜리 논픽션 ‘헬터 스켈터’(글항아리) |
| 4 | ●제목(누구 지음) | `●\s*([^(●=]{2,40}?)\s*\([^)]*지음[^)]*\)` | ●금의 역사(앨런 에리이라 지음)= |
| 5 | 책을 가리키는 낱말 + 따옴표 | `(저서|책|신간|신작|소설|장편|단편집|에세이|그림책|시집|회고록|평전|산문집|번역서)\s*[‘'“"](…)[’'”"]` | 저서 '언캐니 뮤즈'는 / 신작 ‘가호’ |
| 6 | [신간]·[새책] 뒤 제목 | 태그 `\[(?:\d+자\s*)?(?:신간|새책|책꽂이|새로 나왔어요)\]`를 지운 나머지가 20자 이하이고, 쉼표가 없고, 문장 끝(다·요·나·까·죠·…·?·!·.)이 아닐 때 | [새책] 평행우주 / 미래 식량을 설계하라 外 [신간] |
| 7 | '신간·새책' 제목 끝 따옴표 | 제목에 신간/새책이 있고, 끝이 `'제목'`(뒤에 [신간] 허용)으로 끝날 때 | [신간] 트렌드 어떻게 읽을 것인가…'트렌드 리터러시' |
| 8 | [코너] ‘제목’ 외 | `^\[[^\]]+\]\s*[‘'](…)[’']\s*(외|外)` | [북카페] ‘왜 다시 아시아인가’ 외 |
| ~~9~~ | ~~한겨레 서평 제목의 따옴표 낱말~~ | **2026-10-30 삭제**: '억울함'·'오리'처럼 책 제목이 아닌 경우가 대부분이었음 | |

뒷정리:

- 끝의 `외`/`外` 지우기, 공백 정리
- 2~40자만, 숫자만인 것 제외
- `(문학상|노벨상|부커상|베스트셀러)$`로 끝나면 제외('노벨 문학상' 같은 오검출)
- 같은 기사 안 중복 제거(낱말만 남긴 비교)

> **알려진 한계**: 기사 제목의 따옴표 낱말은 책 제목이 아닐 때가 많습니다. 그래서 진열대에는 서점에서 찾은 책만 올립니다(6장 앞, 4장 참고). 동아 '책의 향기'처럼 제목에 책 이름 없이 내용만 쓰는 서평은 요약에도 책 이름이 없으면 빠집니다.

## 4. 책 단위로 모으기 (`book_titles`)

- **같은 책 판단 키**: 책 이름에서 글자·숫자 외의 기호와 공백을 모두 지우고 소문자로(`re.sub(r"\W", "", 이름).lower()`)
- 책마다 기록: 처음 뽑힌 이름, 소개한 **신문사 목록**, 그 책을 다룬 **기사 목록**, 가장 최근 소개일
- **순서**: 소개한 신문사 수가 많은 순 → 같으면 최근 소개일 순
- 화면에는 60권까지(오른쪽 'TOP'은 20권)
- **진열대·TOP 20에는 서점(예스24)에서 찾은 책만** 올립니다(2026-10-30). 못 찾은 이름은 책 제목이 아닌 낱말인 경우가 대부분이고, 표지 대신 기사 사진이 들어가 일그러져 보였기 때문입니다. 서점에 늦게 올라오는 신간은 하루 한 번 다시 찾으므로 찾는 대로 진열대에 나타납니다.

## 5. 서지 정보 붙이기 (`enrich_book_titles`)

### 5-1. 예스24 — 정확한 이름·저자·출판사·출간 연월·표지 (`yes24_lookup`)

- 검색 주소: `https://www.yes24.com/Product/Search?domain=BOOK&query=<책 이름>`
  - robots.txt가 `/Product/Search`를 허용(2026-10-24 확인). 호출 전에 매번 robots.txt를 확인합니다.
- 결과 목록 `<ul id="yesSchList">`의 앞 6개 항목(`<li data-goods-no="번호">`)에서:

| 값 | 찾는 곳 |
|---|---|
| 책 이름 | `class="gd_name"` 링크 글자 |
| 저자·역자 | `class="authPub info_auth"` (예: `무라카미 하루키 저 · 홍은주 역`) |
| 출판사 | `class="authPub info_pub"` |
| 출간 연월 | `class="authPub info_date"` (예: `2026년 10월`) |
| 표지 | `https://image.yes24.com/goods/{번호}/L` (목록용 중간 크기는 `/M`) |
| 책 페이지 | `https://www.yes24.com/product/goods/{번호}` |

- 이름이 맞는 항목이 여럿이면 **출간 연월이 가장 최근인 책**을 고릅니다(옛 판·세트보다 신간 우선).

### 5-2. 같은 책인지 판단 (`_bk_match`) — 가장 중요한 규칙

기사에서 뽑은 이름(A)과 서점 책 이름(B)을, 괄호 내용을 지우고 기호를 없앤 키로 비교합니다.

1. 키가 같으면 일치 (괄호 포함 키가 같아도 일치: `정희(正熙)` = `정희正熙`)
2. B가 A로 시작하면:
   - A가 **8자 이상**이면 일치
   - 아니면 뒤에 붙은 것이 `숫자(권)`, `세트`, `개정판`, 영문/숫자 부제일 때만 일치
     (`파친코` → `파친코 세트` ○, `김밥 책` → `김밥 책 The Gimbap Book` ○, `나의 마을` → `나의 마을이 불타고 있다` ✕)
3. A가 4자 이상이고 B가 **띄어쓰기 경계에서** A로 끝나면 일치
   (`인생의 효율` → `더 늦기 전에 인생의 효율` ○, `빛으로 쓴 편지` → `햇빛으로 쓴 편지` ✕)

짧은 이름을 느슨하게 맞추면 다른 책이 붙는 일이 실제로 생겼기 때문에(나의 마을 → 나의 마을이 불타고 있다) 이 규칙은 엄격하게 유지합니다.

### 5-3. 교보문고 — ISBN (`kyobo_isbn`)

- 검색 주소: `https://search.kyobobook.co.kr/search?keyword=<책 이름>&gbCode=TOT&target=total`
  - robots.txt는 `/api/`만 막음(2026-10-24 확인)
- 결과 HTML의 `data-bid="(97[89]\d{10})" data-name="책 이름"` 쌍 중 5-2 규칙으로 이름이 맞는 첫 항목의 `data-bid`가 ISBN-13
- 예스24 정보를 찾은 책만 ISBN을 찾습니다.

### 5-4. 저장과 다시 찾기

- 저장 파일: `history/book_info.json` — 키는 4장의 '같은 책 판단 키'

```json
"가호": {"name": "가호", "author": "무라카미 하루키 저 · 홍은주 역", "pub": "문학동네",
         "date": "2026년 10월", "cover": "https://image.yes24.com/goods/197068949/L",
         "url": "https://www.yes24.com/product/goods/197068949", "isbn": "9791141691370"}
```

- 한 번 찾은 책은 다시 검색하지 않습니다. 매시간 갱신해도 서점 호출은 **새로 소개된 책 수만큼**입니다.
- 못 찾은 책은 `{"_t": "날짜"}`로 남기고 **하루에 한 번만** 다시 찾습니다(서점에 늦게 올라오는 신간 대비).
- 한 번에 최대 40권, 동시에 4개씩. 파일에는 최근 800권까지 보관합니다.
- 저장된 정보도 화면에 쓰기 전에 5-2 규칙을 다시 적용합니다. 그래서 규칙을 고치면 예전 오연결이 바로 사라집니다.

### 5-5. 서점에 없는 책

(2026-10-30부터) 진열대에 올리지 않습니다. 예전에는 기사 사진을 표지로 썼는데, 가로 사진이 세로 표지 칸에 들어가 일그러져 보이고 대부분 책 제목이 아닌 낱말이었습니다.

## 6. 기사 분류 (`book_cat`)

책 기사 목록의 분류 버튼용입니다. 위에서부터 차례로 적용합니다.

| 분류 | 조건(제목) |
|---|---|
| 기타(처음엔 숨김) | `[\d+화]`(연재소설), `[편집자 레터]` |
| 어린이·그림책 | 그림책, 어린이, 동화, 청소년, `[그림이 있는…` |

## 7. 화면 구성

**① 이번 주의 책 진열대**
- 표지 바둑판(PC 한 줄 5권, 휴대폰 3권). 표지는 비율 2:3 칸에 **자르지 않고** 넣음(`object-fit: contain`)
- 카드: 표지 → 책 이름(2줄까지) → 저자 첫 이름 · 출판사 → `ISBN: 번호` + 복사 버튼(숫자만 복사) → 소개한 신문사 이름(두 곳 이상이면 빨강)
- 정렬: 많이 소개된 순 / 최신순

**② 책 정보 창** — 책을 누르면 뜸
- PC는 화면 가운데 창, 휴대폰은 아래에서 올라오는 창(`<dialog>`). ✕·바깥·ESC로 닫힘
- 큰 표지, 『이름』, 저자·역자, 출판사·출간 연월, ISBN(복사), 소개한 신문사
- 버튼: **파주시 도서관에서 찾기**, 예스24
  - 파주시 도서관 검색 주소(서명 검색):
    `https://lib.paju.go.kr/jalib/plusSearchResultList.do?searchType=SIMPLE&searchCategory=ALL&searchLibrary=ALL&searchKey=TITLE&searchKeyword=<책 이름>`
  - 다른 지역 도서관을 쓸 때는 이 주소만 바꾸면 됩니다.
- '이 책을 다룬 기사': 신문사(신문사마다 고정 색 꼬리표) · 제목 · 날짜 · 요약 2줄

**③ 책 기사 목록** — 분류 버튼(6장), 사진 100×140, 요약 3줄, 책이 연결된 기사엔 '『이름』 책 정보' 링크

**④ 오른쪽 칸** — 많이 소개된 책 TOP 20(책 이름 + 신문사 이름). 누르면 ② 창

## 8. 데이터 구조

**책 기사(`books`, data.json)**

```json
{"title": "[신간] 『한 줄 메모의 힘』", "url": "https://www.readersnews.com/news/articleView.html?idxno=...",
 "outlet": "독서신문", "img": "https://...jpg", "date": "2026-10-23T09:12:00+09:00",
 "desc": "메모 한 줄이 생각을 바꾼다. …"}
```

**책 정보(`book_info`, data.json)**: 5-4의 저장 형식과 같고, 이번 목록에 든 책만 담습니다.

책 목록(이름·신문사·기사 번호)은 저장하지 않고 화면을 만들 때마다 `books`에서 다시 계산합니다. 그래서 규칙을 고치면 다시 모으지 않아도 바로 반영됩니다.

## 10. 다른 프로젝트에 옮길 때

1. **최소 구성**: 2장(모으기) → 3장(이름 뽑기) → 4장(모으기) → 5장(서지 정보)만 있으면 '이번 주의 책' 목록이 나옵니다. 6·7장은 화면용입니다.
2. **떼어 갈 함수**(`trend_site.py`): `fetch_feed`, `item_date`, `item_image`, `item_desc`, `fetch_books`, `enrich_books`(+ `gn_decode`, `og_meta`), `book_titles_of`, `book_titles`, `_bk_key`, `_bk_match`, `yes24_lookup`, `kyobo_isbn`, `enrich_book_titles`, `book_cat`, `robots_allows`, `http_get`.
3. **바꿔야 할 값**: 출처 목록(`BOOK_FEEDS`, `BOOK_SEARCH`, `BOOK_SEARCH_OUTLETS`), 기간(7일), 지역 도서관 검색 주소(`PAJU_LIB`), 저장 파일 위치.
4. **점검 순서**(실제로 겪은 문제들):
   - 출처마다 0건이 아닌지 → 0건이면 날짜 없는 피드(한겨레)나 깨진 XML(연합)을 의심

   - 표지가 잘리지 않는지 → RSS 사진이 잘린 썸네일이면 원문 `og:image`로
